# Microwave rotational spectroscopy profile

Use this optional profile only for microwave rotational spectroscopy libraries. The generic profile never adds these tags.

## Approved tags

- `体系：` molecular system, complex, or isotopic species
- `实验：` CP-FTMW, cavity FTMW, chirped-pulse FTMW, or related experiment
- `证据：` rotational constants, dipole selection, isotopic substitution, hyperfine, or fit residual evidence
- `计算：` electronic-structure method or conformer-search method
- `状态：待获取全文`, `状态：全文已核查`, `状态：深度精读`

## Evidence-bounded note fields

Record the following only at the evidence level justified by the source: rotational constants A/B/C; dipole components; centrifugal distortion; hyperfine parameters; isotopologues; computational level; conformer topology; and assignment basis. Exact values, quotations, and page-level claims require verified full text or a deep read.
